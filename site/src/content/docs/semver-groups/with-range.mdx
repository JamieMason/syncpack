Ensure all dependencies within this group have the specified semver range.

## Configuration

### range <Badge text="Required" variant="danger" />

Which semver range every dependency in this group should use.

| Value  | Example   |
| ------ | --------- |
| `""`   | `1.2.3`   |
| `"^"`  | `^1.2.3`  |
| `"~"`  | `~1.2.3`  |
| `">="` | `>=1.2.3` |
| `">"`  | `>1.2.3`  |
| `"<="` | `<=1.2.3` |
| `"<"`  | `<1.2.3`  |
| `"*"`  | `*`       |

```json title=".syncpackrc.json"
{
  "semverGroups": [
    {
      "dependencies": ["@foo/**"],
      "range": "~"
    }
  ]
}
```
