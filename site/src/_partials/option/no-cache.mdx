Bypass the on-disk cache of npm registry responses. By default Syncpack stores responses for 30 minutes in `$XDG_CACHE_HOME/syncpack`, else `$HOME/.cache/syncpack`, else the system temp directory, to avoid repeat network calls; this flag skips both reading and writing the cache for the current run.

<Code code={`syncpack ${props.command} --no-cache`} lang="bash" />
